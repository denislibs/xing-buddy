# xing-buddy

Пиксельный питомец Синсин (обезьянка) для Claude Desktop и Claude Code. Живёт в углу окна Claude и показывает, что сейчас делает Claude: думает, правит файлы, запускает команды, коммитит, ждёт тебя, закончил или упал.

Работает на хуках Claude Code и не трогает само приложение Claude: всё снимается одной командой.

## Что умеет

- **Состояния Claude.** Думает, работает («кручу братишку», вокруг бегает искорка Claude), ждёт разрешения, успех, ошибка. Отдельные анимации для bash и для 17 git-действий (commit, push, merge, rebase, conflict, PR, CI…).
- **Бар по наведению.** Новый чат, диктовка, помодоро, мини-игра, свернуть.
- **Контекст и лимиты.** Заполненность контекста сессии, потраченные токены, лимиты 5 часов и недели.
- **Уровни.** 20 званий от «Малыша» до «Бессмертного». Он меняется внешне: бейдж, пояса, седина гуру, аура, нимб. Окно «Путь Синсина» со всеми уровнями.
- **Спросить Синсина.** Короткие ответы через Haiku (нужен залогиненный `claude` в терминале).
- **Распорядок.** Обед 13:00–14:30, в будни после 18:30 уходит домой.
- **Забота и игры.** Покормить, искупать, банановый магазин, квест дня, ачивки, коллекция пасхалок, мини-игра «банановый раннер».
- **Прочее.** Недельный отчёт, напоминания размяться, погода, реакция на музыку в Spotify, слежение за Docker-контейнерами, перетаскивание файла на Синсина → готовый промпт в Claude.
- **Свои персонажи** как плагины, см. [CHARACTERS.md](CHARACTERS.md).

Всё включается и выключается в «Настройках» (правый клик по Синсину).

## Windows

### Готовая сборка

1. Скачай `xing-buddy-windows.zip` из [Releases](../../releases) и распакуй в постоянную папку, например `%USERPROFILE%\xing-buddy`.
2. Установи хуки и автозапуск (копия `~/.claude/settings.json` сохранится в `backup\`):

```powershell
.\xing-pixel.exe --install
```

Убрать хуки и автозапуск:

```powershell
.\xing-pixel.exe --uninstall
```

### Сборка из исходников

Нужен только .NET Framework 4.x, он есть в Windows 10/11:

```powershell
.\windows\build.ps1
```

Скрипт собирает `windows\xing-pixel.exe`, примеры персонажей и выгружает спрайты для macOS в `mac\sprites`.

## macOS

Нужны только Xcode Command Line Tools:

```bash
cd mac && chmod +x build.sh && ./build.sh
```

Подробности — в [mac/README.md](mac/README.md). Спрайты в `mac/sprites` генерирует Windows-сборка, они уже лежат в репозитории.

## Как это устроено

- Хуки Claude Code (`UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop` и др.) вызывают `xing-pixel --event`. Процесс записывает событие в `event.json` и сразу завершается, а окно Синсина его подхватывает.
- Окно Синсина — прозрачное окно поверх Claude Desktop. Внутрь приложения Claude ничего не внедряется.
- Пиксель-арт рисуется кодом (`windows/src/Sprites.cs`).
- Нагрузка: около 0,2% CPU и около 130 МБ памяти.

Данные (настройки, статистика, память по проектам) хранятся локально рядом с exe на Windows и в `~/.claude-mascot-pixel` на macOS.
